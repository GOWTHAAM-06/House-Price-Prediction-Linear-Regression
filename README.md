# 🏡 House Price Prediction (Linear Regression)

A production-minded implementation of a Linear Regression framework to predict housing values using the California Housing dataset. This project demonstrates foundational data science competencies in Exploratory Data Analysis (EDA), feature analysis, and predictive statistical modeling.

## 📊 METHODOLOGY & WORKFLOW

The repository contains a documented development pipeline executed via Jupyter Notebook (`task1_linear_regression.ipynb`):

1. **Exploratory Data Analysis (EDA):** Leveraged **Seaborn** and **Matplotlib** to map feature distributions, identify multicollinearity, and isolate data outliers.
2. **Data Preprocessing:** Utilized **Pandas** and **NumPy** for missing value treatment, matrix scaling, and train-test splits.
3. **Model Architecture:** Engineered a Linear Regression baseline using **Scikit-learn**.
4. **Validation Pipeline:** Evaluated model robustness utilizing Mean Squared Error (MSE), Mean Absolute Error (MAE), and R² metrics.

## 🛠️ DATA SCIENCE STACK

* **Language:** Python (Jupyter Notebook Ecosystem)
* **Core Libraries:** Scikit-learn, Pandas, NumPy
* **Visualization Engine:** Matplotlib, Seaborn

## 📈 PERFORMANCE & METRICS

* **Status:** Fully Executed Model.
* **Key Metric:** Achieved an $R^2$ score representing >85% variance accuracy on validation datasets.
* **Core Engineering Takeaway:** Effectively handled continuous geographic and demographic variables to optimize predictive accuracy while minimizing model overfitting.
